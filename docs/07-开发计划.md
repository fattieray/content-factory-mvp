## 四、风险与应对

| 风险 | 可能性 | 影响 | 应对方案 |
|------|--------|------|---------|
| Prompt 效果差 | 高 | 高 | 预留调试时间，准备备用 Prompt |
| API 调用失败 | 中 | 高 | 添加重试机制，降级提示 |
| 进度延期 | 中 | 中 | 优先保证 P0 功能，P1 功能可延后 |
| 人员变动 | 低 | 高 | 文档齐全，随时可交接 |
