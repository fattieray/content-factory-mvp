## 一、Prompt 设计原则

### 1.1 核心原则

**清晰**：指令明确，无歧义

**结构化**：分层级，易理解

**可迭代**：基于反馈持续优化

### 1.2 设计目标

- 特征提取准确率 > 90%
- 生成内容可用率 > 80%
- 用户满意度 > 4/5

---

## 二、特征提取 Prompt

### 2.1 L1 结构层 Prompt

```
请分析以下文章的整体结构：

1. 开头方式：如何引入话题？
2. 段落组织：如何递进/展开？
3. 结尾方式：如何收尾点题？

请用以下格式输出：
{
  "opening": "开头方式描述",
  "progression": "段落组织方式",
  "ending": "结尾方式"
}

文章：
{content}
```

### 2.2 L2 逻辑层 Prompt

```
请分析以下文章的论证逻辑：

1. 核心论点是什么？
2. 用什么方式论证（案例/数据/对比/引用）？
3. 观点之间的推演关系是什么？

请用以下格式输出：
{
  "core_argument": "核心论点",
  "evidence_types": ["案例", "数据"],
  "reasoning_method": "推演方法"
}

文章：
{content}
```

### 2.3 L3 视角层 Prompt

```
请分析以下文章的切入角度：

1. 从什么角度切入问题？
2. 有什么独特视角？
3. 受众是谁，立场是什么？

请用以下格式输出：
{
  "angle": "切入角度",
  "unique_perspective": "独特视角",
  "audience": "目标受众",
  "stance": "立场"
}

文章：
{content}
```

### 2.4 L4 表达层 Prompt

```
请分析以下文章的语言表达：

1. 句式特点（长短句/排比/疑问）？
2. 用词习惯（专业术语/口语化/金句）？
3. 语气特点（犀利/温和/幽默）？

请用以下格式输出：
{
  "sentence_pattern": "句式特点",
  "word_choice": "用词习惯",
  "tone": "语气特点"
}

文章：
{content}
```

### 2.5 L5 素材层 Prompt

```
请分析以下文章使用的素材类型：

1. 案例类型（名人/企业/亲身/虚构）？
2. 数据引用（统计数据/研究结论）？
3. 引用来源（名言/书籍/报告）？

请用以下格式输出：
{
  "case_types": ["案例类型"],
  "data_types": ["数据类型"],
  "quote_sources": ["引用来源"]
}

文章：
{content}
```

## 三、内容生成 Prompt

### 3.1 综合生成 Prompt

```
请根据以下风格特征，写一篇关于{topic}的文章。

【风格特征】
结构特征：{L1_structure}
逻辑特征：{L2_logic}
视角特征：{L3_perspective}
表达特征：{L4_expression}
素材特征：{L5_material}

【用户素材】
{personal_materials}

【要求】
- 字数约{word_count}字
- 保持相同的结构和风格
- 融入用户的个人素材
- 观点清晰，有案例支撑
- 适合发布在公众号/知乎

请生成文章：
```

### 3.2 多版本生成 Prompt

```
请根据以下风格特征，生成 4 个不同版本的文章。

【风格特征】
（同上）

【版本策略】
版本 1（专业深沉型）：强调方法论框架，A 特征 70%
版本 2（平衡型）：A 和 B 特征各 50%
版本 3（个人风格型）：强调个人特色，B 特征 70%
版本 4（创意探索型）：尝试新角度，动态调整

【要求】
每个版本：
- 字数约{word_count}字
- 有明显风格差异
- 保持内容质量

请生成 4 个版本：
```

### 4.2 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 特征提取不准确 | Prompt 太笼统 | 增加具体示例 |
| 生成内容跑题 | 主题约束不足 | 强化主题约束 |
| 风格不一致 | 特征权重不清 | 明确权重参数 |
