# 验收标准

## 一、验收概述

### 1.1 验收目的

本文档定义 MVP 产品的验收标准，确保产品发布前满足质量要求和用户期望。

### 1.2 验收范围

| 模块 | 验收内容 | 优先级 |
|------|----------|--------|
| 用户系统 | 注册、登录、个人信息 | P0 |
| 风格训练 | 样本上传、模型训练、状态管理 | P0 |
| 内容生成 | 任务创建、多版本生成、结果展示 | P0 |
| 内容管理 | 版本选择、导出、历史记录 | P0 |
| 性能安全 | 响应时间、并发能力、数据安全 | P1 |

### 1.3 验收环境

| 环境 | 配置 | 用途 |
|------|------|------|
| 前端 | Vercel Preview | 功能验收 |
| 后端 | Railway Staging | API 验收 |
| 数据库 | Supabase Dev | 数据验收 |

## 二、功能验收标准

### 2.1 用户系统

#### 2.1.1 用户注册

**验收标准**：

- [ ] 用户可以使用邮箱 + 密码注册
- [ ] 邮箱格式验证正确
- [ ] 密码强度校验（至少 8 位）
- [ ] 已注册邮箱提示友好
- [ ] 注册成功后自动登录
- [ ] 注册流程完成时间 < 2 分钟

**验收方法**：手动测试 5 个不同场景

#### 2.1.2 用户登录

**验收标准**：

- [ ] 已注册用户可正常登录
- [ ] 错误密码提示友好（不暴露账号存在性）
- [ ] 登录状态保持（7 天免登录）
- [ ] Token 过期自动刷新
- [ ] 登出后 Token 失效

**验收方法**：手动测试 + 自动化测试

#### 2.1.3 个人信息

**验收标准**：

- [ ] 可查看和编辑个人信息
- [ ] 公司名称、职位可选填
- [ ] 修改后实时保存
- [ ] 头像上传（可选功能）

---

### 2.2 风格训练模块

#### 2.2.1 样本上传

**验收标准**：

- [ ] 支持 Markdown 格式上传
- [ ] 支持直接粘贴文本
- [ ] 单篇最小 500 字，最大 50000 字
- [ ] 最少上传 5 篇，最多 20 篇
- [ ] 实时显示字数统计
- [ ] 支持删除已上传样本
- [ ] 上传进度显示

**验收方法**：上传 10 篇不同长度文章测试

#### 2.2.2 模型训练

**验收标准**：

- [ ] 点击训练后任务正确创建
- [ ] 训练进度实时更新（每 5 秒）
- [ ] 训练预计时间显示
- [ ] 训练完成自动通知
- [ ] 训练失败显示原因并提供重试
- [ ] 训练完成后模型状态变为"就绪"

**验收标准指标**：
- 训练成功率 ≥ 95%
- 平均训练时间 < 10 分钟（5 篇样本）

#### 2.2.3 风格模型管理

**验收标准**：

- [ ] 可创建多个风格模型（最多 3 个）
- [ ] 可切换默认模型
- [ ] 可删除模型（带确认）
- [ ] 模型列表显示训练样本数
- [ ] 模型状态清晰标识（训练中/就绪/失败）

---

### 2.3 内容生成模块

#### 2.3.1 生成任务创建

**验收标准**：

- [ ] 可选择风格模型
- [ ] 可输入 1-5 个主题
- [ ] 每个主题可输入要点提示
- [ ] 可选择目标平台（公众号/知乎/通用）
- [ ] 可设置目标字数范围
- [ ] 提交后跳转到结果页面

**验收方法**：创建 20 个不同配置的生成任务

#### 2.3.2 生成过程

**验收标准**：

- [ ] 显示生成进度（0-100%）
- [ ] 预计完成时间显示
- [ ] 支持后台生成（可离开页面）
- [ ] 生成完成推送通知
- [ ] 生成失败显示原因

**验收标准指标**：
- 生成成功率 ≥ 95%
- 平均生成时间 < 60 秒

#### 2.3.3 结果展示

**验收标准**：

- [ ] 生成 4 个不同版本
- [ ] 每个版本显示完整内容
- [ ] 显示风格相似度评分
- [ ] 支持版本间切换对比
- [ ] 支持全文搜索
- [ ] 支持一键复制

**验收方法**：检查 50 次生成结果

#### 2.4.1 版本选择

**验收标准**：

- [ ] 支持分页加载（每页 20 条）

- [ ] 支持按状态筛选
- [ ] 可点击查看详情

## 三、性能验收标准

### 3.1 响应时间

| 接口/操作 | P50 | P95 | P99 | 不达标处理 |
|-----------|-----|-----|-----|------------|
| 页面加载 | < 1s | < 3s | < 5s | 优化资源 |
| 列表接口 | < 200ms | < 500ms | < 1s | 添加索引 |
| 查询接口 | < 100ms | < 300ms | < 500ms | 优化查询 |
| 生成接口 | < 30s | < 60s | < 90s | 异步处理 |
| 文件上传 | < 2s | < 5s | < 10s | CDN 加速 |

**验收方法**：k6 负载测试，100 并发用户，持续 10 分钟

### 3.2 并发能力

| 指标 | 目标值 | 测量方法 |
|------|--------|----------|
| 同时在线用户 | ≥ 500 | 负载测试 |
| 同时生成任务 | ≥ 50 | 压力测试 |
| API QPS | ≥ 100 | 压力测试 |
| 数据库连接 | ≤ 80% 使用率 | 监控 |

### 3.3 资源使用

| 资源 | 目标值 | 告警值 |
|------|--------|--------|
| CPU 使用率 | < 60% | > 80% |
| 内存使用率 | < 70% | > 85% |
| 磁盘使用率 | < 60% | > 80% |
| 网络带宽 | < 50% | > 80% |

## 四、安全验收标准

### 4.1 认证授权

**验收标准**：

- [ ] 密码加密存储（bcrypt）
- [ ] JWT Token 有效期合理（access: 2h, refresh: 7d）
- [ ] 未登录用户无法访问受保护接口
- [ ] 用户只能访问自己的数据（RLS）
- [ ] Token 泄露可快速失效

**验收方法**：安全测试 + 代码审查

### 4.2 数据安全

**验收标准**：

- [ ] 敏感数据加密传输（HTTPS）
- [ ] 数据库备份每日执行
- [ ] 用户数据逻辑隔离
- [ ] 无 SQL 注入风险
- [ ] 无 XSS 漏洞

**验收方法**：OWASP ZAP 扫描 + 手动测试

### 4.3 API 安全

**验收标准**：

- [ ] 请求频率限制（100 次/分钟）
- [ ] 请求参数验证
- [ ] 错误信息不泄露敏感数据
- [ ] CORS 配置正确
- [ ] CSRF 防护启用

## 八、验收流程

### 8.1 验收阶段

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  开发自测   │ →  │  QA 验收    │ →  │  产品验收   │
│  (100% 通过) │    │  (100% 通过) │    │  (关键流程)  │
└─────────────┘    └─────────────┘    └─────────────┘
                                              ↓
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  用户内测   │ ←  │  发布准备   │ ←  │  问题修复   │
│  (反馈收集) │    │  (检查清单) │    │  (P0/P1)    │
└─────────────┘    └─────────────┘    └─────────────┘
```

### 8.2 验收检查清单

**开发自测**：
- [ ] 单元测试通过率 100%
- [ ] 集成测试通过率 100%
- [ ] 代码审查完成
- [ ] 无 P0/P1 级别 Bug

**QA 验收**：
- [ ] 所有 P0 测试用例通过
- [ ] 所有 P1 测试用例通过
- [ ] P2 测试用例通过率 ≥ 95%
- [ ] 性能测试达标
- [ ] 安全测试通过

**产品验收**：
- [ ] 核心流程演示通过
- [ ] UI/UX 符合设计
- [ ] 用户文档完整

**用户内测**：
- [ ] 20 位种子用户完成测试
- [ ] 收集反馈 ≥ 50 条
- [ ] NPS ≥ 50
- [ ] 严重问题已修复

### 8.3 验收报告

验收完成后输出《验收报告》，包含：

1. 验收概述
2. 测试结果汇总
3. 缺陷统计
4. 风险评估
5. 发布建议

## 九、缺陷分级标准

| 级别 | 定义 | 修复要求 |
|------|------|----------|
| P0 - 致命 | 系统崩溃、数据丢失、核心功能不可用 | 必须修复，否则不发布 |
| P1 - 严重 | 主要功能受影响，无替代方案 | 必须修复，否则不发布 |
| P2 - 一般 | 功能异常但有替代方案 | 建议修复，可带病发布 |
| P3 - 轻微 | 体验问题、cosmetic 问题 | 后续迭代修复 |

- [ ] 用户文档完整
- [ ] 监控告警配置完成

### 10.2 发布后监控

| 指标 | 告警阈值 | 响应时间 |
|------|----------|----------|
| 错误率 | > 5% | 15 分钟 |

| 生成失败率 | > 10% | 30 分钟 |
| 用户投诉 | > 5 个/小时 | 1 小时 |
