# 数据库设计

## 一、设计原则

### 1.1 核心原则

- **简洁优先**：MVP 阶段只存储必要数据
- **扩展预留**：关键字段预留扩展空间
- **读写分离**：高频查询优化读取性能
- **数据安全**：用户数据隔离，敏感信息加密

### 1.2 技术选型

| 组件 | 选型 | 理由 |
|------|------|------|
| 主数据库 | Supabase PostgreSQL | 开箱即用，支持实时订阅 |
| 缓存层 | Redis（Upstash） | 低成本，Serverless |
| 文件存储 | Supabase Storage | 与数据库集成，支持 CDN |
| 向量存储 | pgvector 扩展 | PostgreSQL 原生支持 |

## 三、表结构设计

### 3.1 users（用户表）

**用途**：存储用户基本信息

```sql
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    email VARCHAR(255) UNIQUE NOT NULL,
    name VARCHAR(100) NOT NULL,
    company VARCHAR(200),
    title VARCHAR(100),
    industry VARCHAR(50),
    
    -- 订阅信息
    subscription_status VARCHAR(20) DEFAULT 'free',
    subscription_expires_at TIMESTAMP,
    
    -- 元数据
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    last_login_at TIMESTAMP,
    
    -- 索引
    CONSTRAINT email_unique UNIQUE (email)
);

-- 索引
CREATE INDEX idx_users_email ON users(email);
CREATE INDEX idx_users_subscription ON users(subscription_status);
```

**字段说明**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | UUID | 是 | 主键 |
| email | VARCHAR | 是 | 登录邮箱，唯一 |
| name | VARCHAR | 是 | 用户姓名 |
| company | VARCHAR | 否 | 公司名称 |
| title | VARCHAR | 否 | 职位 |
| industry | VARCHAR | 否 | 行业分类 |
| subscription_status | VARCHAR | 是 | free/trial/pro |
| subscription_expires_at | TIMESTAMP | 否 | 订阅到期时间 |

### 3.2 style_models（风格模型表）

**用途**：存储用户训练的风格模型

```sql
CREATE TABLE style_models (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    name VARCHAR(100) NOT NULL,
    description TEXT,
    
    -- 风格特征数据（JSON 存储多层特征）
    style_features JSONB,
    
    -- 训练状态
    status VARCHAR(20) DEFAULT 'training',
    training_progress INT DEFAULT 0,
    
    -- 样本统计
    sample_count INT DEFAULT 0,
    total_word_count INT DEFAULT 0,
    
    -- 元数据
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    trained_at TIMESTAMP,
    
    -- 索引
    CONSTRAINT fk_user FOREIGN KEY (user_id) REFERENCES users(id)
);

-- 索引
CREATE INDEX idx_style_models_user_id ON style_models(user_id);
CREATE INDEX idx_style_models_status ON style_models(status);
CREATE INDEX idx_style_models_features ON style_models USING GIN(style_features);
```

### 3.3 sample_articles（样本文章表）

**用途**：存储用户上传的训练样本

```sql
CREATE TABLE sample_articles (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    style_model_id UUID REFERENCES style_models(id) ON DELETE CASCADE,
    
    -- 文章内容
    title VARCHAR(500) NOT NULL,
    content TEXT NOT NULL,
    
    -- 来源信息
    source_url VARCHAR(500),
    source_type VARCHAR(20) DEFAULT 'upload',
    published_at TIMESTAMP,
    
    -- 文章统计
    word_count INT,
    reading_time INT,
    
    -- 分析结果
    analysis_result JSONB,
    quality_score DECIMAL(3,2),
    
    -- 元数据
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    processed_at TIMESTAMP,
    
    -- 索引
    CONSTRAINT fk_user FOREIGN KEY (user_id) REFERENCES users(id),
    CONSTRAINT fk_style_model FOREIGN KEY (style_model_id) REFERENCES style_models(id)
);

-- 索引
CREATE INDEX idx_sample_articles_user_id ON sample_articles(user_id);
CREATE INDEX idx_sample_articles_model_id ON sample_articles(style_model_id);
CREATE INDEX idx_sample_articles_quality ON sample_articles(quality_score);
CREATE INDEX idx_sample_articles_content ON sample_articles USING GIN(to_tsvector('chinese', content));
```

### 3.4 generations（生成记录表）

**用途**：存储内容生成请求记录

```sql
CREATE TABLE generations (

    target_word_count INT,
    
    -- 生成参数
    generation_params JSONB,

    status VARCHAR(20) DEFAULT 'pending',
    progress INT DEFAULT 0,
    
    -- 结果统计
    version_count INT DEFAULT 0,
    selected_version INT,
    
    -- 元数据

    completed_at TIMESTAMP,
```

### 3.5 generation_versions（生成版本表）

**用途**：存储单次生成的多个版本

```sql
CREATE TABLE generation_versions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    generation_id UUID NOT NULL REFERENCES generations(id) ON DELETE CASCADE,
    version_number INT NOT NULL,
    
    -- 版本内容
    title VARCHAR(500),
    content TEXT NOT NULL,
    
    -- 风格参数
    style_weights JSONB,
    style_score DECIMAL(3,2),
    
    -- 质量指标
    readability_score DECIMAL(3,2),
    coherence_score DECIMAL(3,2),
    
    -- 用户反馈
    user_rating INT,
    user_feedback TEXT,
    is_selected BOOLEAN DEFAULT FALSE,
    
    -- 元数据
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    -- 索引
    CONSTRAINT fk_generation FOREIGN KEY (generation_id) REFERENCES generations(id),
    CONSTRAINT unique_version UNIQUE (generation_id, version_number)
);

-- 索引
CREATE INDEX idx_versions_generation_id ON generation_versions(generation_id);
CREATE INDEX idx_versions_selected ON generation_versions(is_selected);
CREATE INDEX idx_versions_content ON generation_versions USING GIN(to_tsvector('chinese', content));
```

### 3.6 analytics（分析事件表）

**用途**：存储用户行为分析数据

```sql
CREATE TABLE analytics (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    generation_id UUID REFERENCES generations(id) ON DELETE SET NULL,
    
    -- 事件信息
    event_type VARCHAR(50) NOT NULL,
    event_category VARCHAR(50),
    event_data JSONB,
    
    -- 元数据
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    -- 索引
    CONSTRAINT fk_user FOREIGN KEY (user_id) REFERENCES users(id)
);

-- 索引
CREATE INDEX idx_analytics_user_id ON analytics(user_id);
CREATE INDEX idx_analytics_type ON analytics(event_type);
CREATE INDEX idx_analytics_created ON analytics(created_at DESC);
CREATE INDEX idx_analytics_data ON analytics USING GIN(event_data);
```

**事件类型示例**：

## 四、数据迁移

### 4.1 初始迁移

```sql
-- 启用必要扩展
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
CREATE EXTENSION IF NOT EXISTS "pg_trgm";
CREATE EXTENSION IF NOT EXISTS "vector";

-- 创建所有表（见上文）

-- 创建触发器（自动更新 updated_at）
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = CURRENT_TIMESTAMP;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER update_users_updated_at BEFORE UPDATE ON users
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

CREATE TRIGGER update_style_models_updated_at BEFORE UPDATE ON style_models
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();
```

## 五、安全策略

### 5.1 RLS（行级安全）

```sql
-- 启用 RLS
ALTER TABLE users ENABLE ROW LEVEL SECURITY;
ALTER TABLE style_models ENABLE ROW LEVEL SECURITY;
ALTER TABLE sample_articles ENABLE ROW LEVEL SECURITY;
ALTER TABLE generations ENABLE ROW LEVEL SECURITY;
ALTER TABLE generation_versions ENABLE ROW LEVEL SECURITY;
ALTER TABLE analytics ENABLE ROW LEVEL SECURITY;

-- 用户只能访问自己的数据
CREATE POLICY users_isolation ON users
    USING (auth.uid()::text = id::text);

CREATE POLICY style_models_isolation ON style_models
    USING (auth.uid()::text = user_id::text);

CREATE POLICY sample_articles_isolation ON sample_articles
    USING (auth.uid()::text = user_id::text);

CREATE POLICY generations_isolation ON generations
    USING (auth.uid()::text = user_id::text);

CREATE POLICY generation_versions_isolation ON generation_versions
    USING (
        generation_id IN (
            SELECT id FROM generations WHERE user_id = auth.uid()
        )
    );

CREATE POLICY analytics_isolation ON analytics
    USING (auth.uid()::text = user_id::text);
```

## 六、性能优化

### 6.1 查询优化

```sql
-- 常用查询物化视图
CREATE MATERIALIZED VIEW mv_user_stats AS
SELECT 
    u.id,
    u.email,
    COUNT(DISTINCT sm.id) as model_count,
    COUNT(DISTINCT g.id) as generation_count,
    COUNT(DISTINCT gv.id) as version_count,
    MAX(g.created_at) as last_generation_at
FROM users u
LEFT JOIN style_models sm ON u.id = sm.user_id
LEFT JOIN generations g ON u.id = g.user_id
LEFT JOIN generation_versions gv ON g.id = gv.generation_id
GROUP BY u.id;

-- 刷新策略：每小时
CREATE INDEX idx_mv_user_stats_id ON mv_user_stats(id);
```

### 6.2 缓存策略

| 数据类型 | 缓存策略 | TTL |
|----------|----------|-----|

| 生成历史 | 数据库 + 分页 | - |
| 分析数据 | 数据库聚合 | - |

## 七、监控与告警

### 7.1 关键指标

```sql
-- 每日新增用户
SELECT DATE(created_at) as date, COUNT(*) as new_users
FROM users
GROUP BY DATE(created_at)
ORDER BY date DESC;

-- 每日生成次数
SELECT DATE(created_at) as date, COUNT(*) as generations
FROM generations
GROUP BY DATE(created_at)
ORDER BY date DESC;

-- 风格模型训练成功率
SELECT 
    COUNT(*) FILTER (WHERE status = 'ready') as ready_count,
    COUNT(*) FILTER (WHERE status = 'failed') as failed_count,
    COUNT(*) as total
FROM style_models;
```
