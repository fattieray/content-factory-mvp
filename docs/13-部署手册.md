## 一、部署准备

### 1.1 环境要求

| 组件 | 要求 | 说明 |
|------|------|------|
| Node.js | 18.x+ | 前端构建 |
| Python | 3.11+ | 后端运行 |
| Docker | 最新 | 容器部署 |

### 1.2 账号准备

- [ ] Vercel 账号
- [ ] Railway 账号
- [ ] Supabase 账号
- [ ] Claude API 账号

### 1.3 环境变量

```bash
# .env
CLAUDE_API_KEY=your_api_key
SUPABASE_URL=your_supabase_url
SUPABASE_KEY=your_supabase_key
JWT_SECRET=your_jwt_secret
```

## 二、前端部署

### 2.1 本地构建

```bash
# 进入前端目录
cd frontend

# 安装依赖
npm install

# 构建
npm run build
```

### 2.2 Vercel 部署

```bash
# 安装 Vercel CLI
npm install -g vercel

# 登录
vercel login

# 部署
vercel --prod
```

### 2.3 配置域名

1. 登录 Vercel Dashboard
2. 选择项目
3. Settings → Domains
4. 添加自定义域名

---

## 三、后端部署

### 3.1 本地测试

```bash
# 进入后端目录
cd backend

# 安装依赖
pip install -r requirements.txt

# 运行
uvicorn main:app --reload
```

### 3.2 Railway 部署

```bash
# 安装 Railway CLI
npm install -g @railway/cli

# 登录
railway login

# 初始化项目
railway init

# 部署
railway up
```

### 3.3 配置环境变量

在 Railway Dashboard 中配置：
- CLAUDE_API_KEY
- SUPABASE_URL
- SUPABASE_KEY
- JWT_SECRET

## 四、数据库部署

### 4.1 创建 Supabase 项目

1. 登录 Supabase Dashboard
2. 创建新项目
3. 记录 Project URL 和 API Key

### 4.2 执行 SQL 脚本

```sql
-- 创建 users 表
CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email VARCHAR(255) UNIQUE NOT NULL,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- 创建 samples 表
CREATE TABLE samples (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  content TEXT NOT NULL,
  features JSONB,
  created_at TIMESTAMP DEFAULT NOW()
);

-- 创建 generations 表
CREATE TABLE generations (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  sample_id UUID REFERENCES samples(id),
  topic VARCHAR(255) NOT NULL,
  versions JSONB,
  selected_version INTEGER,
  created_at TIMESTAMP DEFAULT NOW()
);
```
