## 一、产品概述

### 1.1 产品定位

面向企业家和科技公司老板的个人 IP 智能内容生成工具，通过 AI 技术帮助用户快速生成符合个人风格的高质量内容。

### 1.2 目标用户

| 用户类型 | 特征 | 需求 |
|---------|------|------|
| **企业家** | 40-55 岁，企业创始人/CEO | 建立个人品牌，但没时间写内容 |
| **科技公司老板** | 35-50 岁，技术出身 | 有专业见解，但不擅长表达 |
| **创业者** | 30-45 岁，A 轮后公司 | 需要融资，需要提升行业影响力 |

### 1.3 核心价值

**对用户**：把好文章丢进去，生成类似风格的新文章

**对产品**：验证"投喂→生成"核心链路的可行性

### 2.2 功能详细说明

#### F001 样本投喂

**用户故事**：
作为用户，我希望能够粘贴一篇好文章，让 AI 学习它的风格。

**功能描述**：
- 提供文本输入框，支持粘贴文章内容
- 支持字数限制（1000-5000 字）
- 提供示例样本供选择（内置 2-3 个示例）

**验收标准**：
- [ ] 可以粘贴文章内容
- [ ] 有字数限制提示
- [ ] 可以选择示例样本

---

#### F002 特征提取

**用户故事**：
作为用户，我希望 AI 能自动分析文章的特征，让我了解这篇文章好在哪里。

**功能描述**：
- AI 自动分析文章的 5 层特征（L1-L5）
- 以可视化方式展示分析结果
- 支持重新分析

**5 层特征体系**：

| 层级 | 名称 | 说明 |
|------|------|------|
| L1 | 结构层 | 文章的宏观骨架（五段式、起承转合等） |
| L2 | 逻辑层 | 观点的推演方式（归纳法、演绎法等） |
| L3 | 视角层 | 切入问题的角度（反共识、跨界类比等） |
| L4 | 表达层 | 语言的习惯用法（短句、疑问句、排比等） |
| L5 | 素材层 | 论据的类型选择（案例、数据、引用等） |

**验收标准**：
- [ ] 能正确提取 5 层特征
- [ ] 特征展示清晰易懂
- [ ] 支持重新分析

---

#### F003 主题输入

**用户故事**：
作为用户，我希望输入想写的主题，让 AI 基于这个主题生成文章。

**功能描述**：
- 提供主题输入框
- 支持主题建议（基于热点推荐）
- 支持字数要求选择

**验收标准**：
- [ ] 可以输入主题
- [ ] 有主题建议功能
- [ ] 可以选择字数要求

---

#### F004 文章生成

**用户故事**：
作为用户，我希望 AI 能基于样本特征生成新文章，节省我的写作时间。

**功能描述**：
- 基于提取的特征生成文章
- 支持字数控制（1000-3000 字）
- 显示生成进度

**验收标准**：
- [ ] 能生成符合特征的文章
- [ ] 字数符合要求
- [ ] 显示生成进度

---

#### F005 多版本生成

**用户故事**：
作为用户，我希望一次生成多个版本，让我有选择的余地。

**功能描述**：
- 同时生成 4 个候选版本
- 每个版本有不同的风格倾向
- 支持版本对比

**版本类型**：

| 版本 | 定位 | A 特征权重 | B 特征权重 |
|------|------|----------|----------|
| 版本 1 | 专业深沉型 | 70-80% | 20-30% |
| 版本 2 | 平衡型 | 50% | 50% |
| 版本 3 | 个人风格型 | 20-30% | 70-80% |
| 版本 4 | 创意探索型 | 动态调整 | 动态调整 |

**验收标准**：
- [ ] 能生成 4 个版本
- [ ] 每个版本有明显差异
- [ ] 支持版本对比

---

#### F006 内容编辑

**用户故事**：
作为用户，我希望对生成的内容进行简单修改，让它更符合我的需求。

**功能描述**：
- 提供富文本编辑器
- 支持基础格式（加粗、斜体、列表）
- 支持实时保存

**验收标准**：
- [ ] 可以编辑内容
- [ ] 支持基础格式
- [ ] 自动保存

---

#### F007 一键复制

**用户故事**：
作为用户，我希望一键复制生成的内容，方便我发布到公众号/知乎。

**功能描述**：
- 一键复制全部内容
- 复制成功提示
- 支持选择复制部分

**验收标准**：
- [ ] 可以一键复制
- [ ] 有复制成功提示
- [ ] 支持部分复制

| 指标 | 要求 | 说明 |
|------|------|------|
| 响应时间 | <3 秒 | 页面加载时间 |

| 多版本生成 | <60 秒 | 4 个版本生成时间 |

## 四、数据需求

### 4.1 数据模型

#### 用户 (User)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 用户 ID |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

#### 样本 (Sample)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 样本 ID |
| user_id | string | 用户 ID |
| content | text | 样本内容 |
| features | json | 提取的特征 |
| created_at | datetime | 创建时间 |

#### 生成记录 (Generation)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 记录 ID |
| user_id | string | 用户 ID |
| sample_id | string | 样本 ID |
| topic | string | 生成主题 |
| versions | json | 生成的版本 |
| selected_version | int | 选择的版本 |
| created_at | datetime | 创建时间 |

### 4.2 数据流转

```
用户投喂 → 样本存储 → 特征提取 → 特征存储
                                    │
                                    ▼
用户选择 ← 版本存储 ← 文章生成 ← 特征 + 主题
```
