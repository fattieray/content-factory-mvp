## 三、数据库设计

### 3.1 ER 图

```
┌─────────────┐       ┌─────────────┐       ┌─────────────┐
│    User     │       │   Sample    │       │ Generation  │
├─────────────┤       ├─────────────┤       ├─────────────┤
│ id          │◀──────│ user_id     │◀──────│ user_id     │
│ email       │       │ id          │       │ id          │
│ created_at  │       │ content     │       │ sample_id   │
│ updated_at  │       │ features    │       │ topic       │
└─────────────┘       │ created_at  │       │ versions    │
                      └─────────────┘       │ selected    │
                                            │ created_at  │
                                            └─────────────┘
```

### 3.2 表结构

#### users 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| email | varchar | 邮箱 |
| created_at | timestamp | 创建时间 |
| updated_at | timestamp | 更新时间 |

#### samples 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| user_id | uuid | 外键 |
| content | text | 样本内容 |
| features | jsonb | 提取的特征 |
| created_at | timestamp | 创建时间 |

#### generations 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| user_id | uuid | 外键 |
| sample_id | uuid | 外键 |
| topic | varchar | 生成主题 |
| versions | jsonb | 生成的版本 |
| selected_version | int | 选择的版本 |
| created_at | timestamp | 创建时间 |

## 四、API 设计

### 4.1 API 概览

| 接口 | 方法 | 说明 | 认证 |
|------|------|------|------|
| /api/analyze | POST | 分析文章特征 | 需要 |
| /api/generate | POST | 生成文章 | 需要 |
| /api/history | GET | 获取历史记录 | 需要 |
| /api/samples | GET | 获取样本列表 | 需要 |
| /api/samples | POST | 创建样本 | 需要 |

### 4.2 请求响应示例

#### POST /api/analyze

**请求**：
```json
{
  "content": "文章内容..."
}
```

**响应**：
```json
{
  "success": true,
  "data": {
    "sample_id": "uuid",
    "features": {
      "L1_structure": {...},
      "L2_logic": {...},
      "L3_perspective": {...},
      "L4_expression": {...},
      "L5_material": {...}
    }
  }
}
```

#### POST /api/generate

**请求**：
```json
{
  "sample_id": "uuid",
  "topic": "如何打造自驱动团队",
  "version_strategy": "balanced"
}
```

**响应**：
```json
{
  "success": true,
  "data": {
    "generation_id": "uuid",
    "versions": [
      {
        "version": 1,
        "type": "professional",
        "content": "文章内容..."
      },
      ...
    ]
  }
}
```

详细 API 文档见 [05-API 接口文档.md](05-API 接口文档.md)

## 五、部署方案

### 5.1 前端部署 (Vercel)

```yaml
# vercel.json
{
  "buildCommand": "npm run build",
  "outputDirectory": "dist",
  "framework": "vite"
}
```

### 5.2 后端部署 (Railway)

```dockerfile
# Dockerfile
FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install -r requirements.txt

COPY . .

CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```

### 5.3 数据库 (Supabase)

- 使用 Supabase 云数据库
- 免费额度：500MB 存储
- 自动备份

## 六、安全设计

### 6.1 认证机制

- 使用 Supabase Auth
- JWT Token 认证
- Token 有效期 7 天

### 6.2 数据加密

- HTTPS 传输加密
- 敏感数据加密存储
- API Key 环境变量存储

### 6.3 限流策略

| 接口 | 限流 |
|------|------|
| /api/analyze | 10 次/分钟 |
| /api/generate | 5 次/分钟 |
