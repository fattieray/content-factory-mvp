# 03-交互设计文档

> 企业家个人 IP 智能内容工厂 - 交互设计说明

---

## 一、设计原则

### 1.1 核心原则

**极简**：一个页面完成所有操作

**直观**：用户不需要思考，跟着指引走

**高效**：最少点击次数完成目标

### 1.2 设计目标

- 新用户 30 秒内理解产品
- 3 分钟内完成第一次生成
- 5 个点击内完成发布

---

## 二、页面布局

### 2.1 整体布局

```
┌─────────────────────────────────────────────────────────┐
│                    内容工厂 MVP                          │
│                   Logo + 产品名称                        │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ┌──────────────────────┐  ┌──────────────────────┐    │
│  │   投喂样本区域        │  │   写作区域            │    │
│  │                      │  │                      │    │
│  │  [粘贴文章内容...]   │  │  想写什么主题？       │    │
│  │                      │  │  [输入主题]           │    │
│  │  [分析特征]          │  │                      │    │
│  │                      │  │  [生成文章]          │    │
│  └──────────────────────┘  └──────────────────────┘    │
│                                                         │
│  ┌─────────────────────────────────────────────────┐    │
│  │  分析结果                                         │    │
│  │  • 结构：五段式                                  │    │
│  │  • 风格：短句为主                                │    │
│  └─────────────────────────────────────────────────┘    │
│                                                         │
│  ┌─────────────────────────────────────────────────┐    │
│  │  生成结果                                         │    │
│  │  [文章内容...]                                   │    │
│  │                              [复制] [重新生成]   │    │
│  └─────────────────────────────────────────────────┘    │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 2.2 响应式设计

| 屏幕尺寸 | 布局 | 说明 |
|---------|------|------|
| 桌面 (>1024px) | 左右两栏 | 投喂区 + 写作区并排 |
| 平板 (768-1024px) | 上下两栏 | 投喂区在上，写作区在下 |
| 手机 (<768px) | 单栏 | 垂直堆叠 |

## 四、组件设计

### 4.1 投喂区域

```
┌─────────────────────────────────────────────────────────────┐
│  投喂样本                                                    │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │                                                      │   │
│  │  请粘贴一篇您喜欢的文章...                           │   │
│  │                                                      │   │
│  │  [文本输入框，支持 1000-5000 字]                       │   │
│  │                                                      │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  当前字数：0 / 5000                                         │
│                                                             │
│  ┌──────────────┐  ┌──────────────┐                        │
│  │  使用示例    │  │  分析特征    │                        │
│  └──────────────┘  └──────────────┘                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**交互说明**：
- 文本框支持粘贴和输入
- 实时显示字数
- 字数不足时"分析特征"按钮禁用
- 点击"使用示例"自动填充示例文章

## 六、异常处理

### 6.1 错误状态

| 场景 | 提示 | 操作 |
|------|------|------|
| 字数不足 | "请至少输入 1000 字" | 引导继续输入 |
| 生成失败 | "生成失败，请重试" | 提供重试按钮 |
| 网络错误 | "网络连接失败，请检查网络" | 提供重试按钮 |
| API 限额 | "今日生成次数已用完" | 引导升级 |

### 6.2 空状态

| 场景 | 展示 | 引导 |
|------|------|------|
| 无样本 | "还没有投喂样本" | 引导投喂 |
| 无历史 | "还没有生成记录" | 引导生成 |
| 无收藏 | "还没有收藏版本" | 引导收藏 |
